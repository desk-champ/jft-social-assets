# jft-social-assets

Image assets for JFT Hauling Services social media posts, hosted here so the
Metricool scheduler can pull them by URL.

Layout: `posts/<nn>-<item>/` — squares (1:1) for Facebook and LinkedIn,
verticals (4:5) for Instagram and TikTok, `*-graphic*.png` originals for
Facebook and LinkedIn, `*-graphic*-ig.jpg` letterboxed 4:5 copies for Instagram.

Batch 1: 10 item posts, Sep 14–25, 2026.
